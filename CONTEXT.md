# Context

`ChaithawatPon/sell-to-facebook-marketplace` is a public, standalone repository for one portable Marketplace automation skill. It is not a mirror of any private skill directory.

The package may describe a seller-side workflow that depends on a locally logged-in Facebook browser session, but the repository must never include that session, exported conversation history, screenshots, outputs, cookies, or any real listing or buyer data.

All runtime state is recreated locally under the installed skill directory and remains outside version control.
