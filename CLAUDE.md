# Repo notes

This is a single-package public skill repository.

- Package path: `sell-to-facebook-marketplace/`
- Validator: `python3 scripts/validate-skills.py .`
- Package tests: `npm test --prefix sell-to-facebook-marketplace`
- Install helper: `python3 scripts/install-skill.py sell-to-facebook-marketplace --dest "$HOME/.claude/skills"`

Keep public/private boundaries strict: no cookies, no browser state, no outputs, no real buyer text, no private work notes.
